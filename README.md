# Shopping Catch

落ちてくる商品をカゴでキャッチし、60秒間のハイスコアを競うブラウザ向けアクションミニゲームです。PC、スマートフォン、タブレットに対応しています。

- [ゲーム仕様書](docs/仕様書.md)

## ゲームルール

- 通常商品をキャッチすると基本10点を獲得します。
- 商品を連続でキャッチすると、コンボ数に応じてボーナスが加算されます。
- レア商品「🎁」は基本50点で、1プレイに最低1個出現します。
- 危険アイテム「💣」をキャッチすると10点減点され、コンボがリセットされます。
- 通常商品やレア商品を取り逃すと5点減点され、コンボがリセットされます。
- スコアが0点未満になることはありません。

## 起動方法

依存パッケージやビルドは不要です。`index.html` をブラウザで開くか、任意の静的HTTPサーバーでこのディレクトリを配信してください。

例（Pythonがインストール済みの場合）：

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## 操作

- PC：ゲーム画面内でマウスを左右に動かすか、左右矢印キーまたはA/Dキーでカゴを移動します。
- PC：PまたはEscで一時停止・再開します。EnterまたはSpaceでもゲームを開始できます。
- スマートフォン／タブレット：画面下部の左右ボタンを長押ししてカゴを移動します。
- HUDの一時停止ボタンと効果音ON/OFFボタンは、すべての対応端末で利用できます。

ハイスコアと効果音設定はブラウザ内に保存されます。
